ตัวอย่างลูปแบบย่อใน C#

แก่นของ agent คือให้โมเดลเลือกว่าจะตอบหรือเรียก tool แล้วนำผล tool กลับเข้า context เพื่อให้ตัดสินใจรอบถัดไป

while (true)
{
    var response = await llm.SendAsync(messages, tools);

    if (response.ToolCall is null)
        return response.Text; // งานเสร็จ

    ValidatePermission(response.ToolCall);
    var result = await RunTool(response.ToolCall);

    messages.Add(response.AsAssistantMessage());
    messages.Add(ToolResultMessage(result));

    if (++stepCount >= maxSteps)
        throw new InvalidOperationException("Agent exceeded max steps");
}

ควรใช้ Agent หรือ Workflow ธรรมดา?

คุ้มที่จะทำเป็น Agent เมื่อ

  • ลำดับขั้นตอนไม่ตายตัวและขึ้นกับข้อมูลที่เจอระหว่างทาง
  • ต้องเลือกจากหลาย tool หรือค้นข้อมูลหลายรอบ
  • งานต้องตรวจผลของตัวเองแล้วแก้แผนต่อ
  • มี guardrail และ human approval รองรับ action เสี่ยง

Workflow เหมาะกว่าเมื่อ

  • ขั้นตอนชัดและคาดเดาได้อยู่แล้ว
  • ต้องการ deterministic behavior สูง
  • เรื่องผิดพลาดมีต้นทุนสูงและไม่ควรให้โมเดลตัดสินใจลำดับเอง
  • ใช้ if/else หรือ state machine แล้วอ่านง่ายกว่า agent
สรุปสำหรับนำเสนอ / สัมภาษณ์

Agentic AI คือการให้ LLM เป็นตัวตัดสินใจ “ขั้นตอนถัดไป” ภายใต้เครื่องมือและกติกาที่ระบบกำหนดไว้ โดยวน Think → Act → Observe จนบรรลุ goal จุดสำคัญใน production ไม่ใช่แค่เลือกโมเดลเก่ง แต่คือออกแบบ tools, permissions, guardrails, observability และ human-in-the-loop ให้ดี
